# Source Labels

This repo deliberately separates source principles from implementation choices.

## Why Labels Matter

AI assistants often mix three things:

1. What the book says.
2. What a person inferred from examples.
3. What one workspace happens to do.

When those are mixed, the next user cannot tell which parts are required and which parts can change.

## Labels

## Book Principle

A concept treated as core to the 12 Week Year model.

Example:

```text
Keep the 12 week plan focused on one to three goals.
```

## Practical Interpretation

An operational reading that makes the principle usable.

Example:

```text
If you are new, start with one or two goals instead of three.
```

## Implementation Recipe

A specific way to run the system in a tool or workspace.

Example:

```text
In Obsidian, keep the current weekly plan at the top level and move past weeks into past-weeks/.
```

## Example

An illustration, not a rule.

Example:

```text
Health, new business, referrals, real estate, team sales, and home organization are sample-style domains. Replace them with your own.
```

## Rule For AI Assistants

If you are not sure whether something is source truth or implementation advice, label it as a practical interpretation and say what would need checking.
