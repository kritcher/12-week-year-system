# Model Work Week

The Model Work Week is the weekly template that protects execution.

It is not a wish list. It is where the tactics live.

## Three Performance Blocks

## Strategic Block

Use one 3 hour block per week for high-value work connected to the 12 week goals.

Recommended agenda:

| Time | Activity |
| --- | --- |
| 5-10 min | Review vision |
| 10-15 min | Check execution score and lead/lag indicators |
| 10-20 min | Analyze breakdown: plan problem or execution problem? |
| 2-2.5 hr | Do the highest-leverage plan tactics |

Important: the Strategic Block belongs to the cycle, not to one goal by default.

If your intentional imbalance is very heavy toward one goal, that goal may receive most of the work time. But the review, metrics, and breakdown function should still serve the whole cycle.

## Buffer Block

Use 30-60 minutes per day for reactive work:

- email
- messages
- calls
- admin
- small coordination

The goal is to stop reactive work from leaking into every hour.

## Breakout Block

Use one 3 hour block per week for recovery.

This is not planning. It is not reflection. It is not "light work".

## Learning Block

This is not one of the classic three performance blocks, but it is a useful implementation recipe.

Use a Learning Block when a goal needs study or skill acquisition.

Example:

```text
Learning Block: Tuesday, Wednesday, Thursday 14:00-15:30
Tactic: Study the alpha course for 60-90 minutes x 3/week.
```

Do not write:

```text
Study alpha course 3 hours/week in Strategic Block.
```

That turns the Strategic Block into a private course block and removes its review function.

## Booking Order

Recommended order:

1. Weekly planning and score review.
2. Strategic Block.
3. Tactic blocks for the main goals.
4. Buffer Blocks.
5. Breakout Block.
6. Maintenance blocks.

If it does not fit, the plan is too large.
