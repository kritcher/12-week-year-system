# Goals, Tactics, Concepts, And Milestones

This is the section to give an AI before it writes your plan.

## Definitions

| Layer | Meaning | Example |
| --- | --- | --- |
| Concept | A broad idea or domain | `exercise`, `get referrals`, `organize home` |
| Goal | A measurable 12 week outcome | `Close 10 qualified client meetings` |
| Milestone | A checkpoint or deliverable | `referral script completed`, `file system ready` |
| Tactic | A committed action that can be executed and scored | `Ask for referrals 2x/day`, `do cardio 2x/week` |

## The Tactic Test

A tactic should pass most of these:

- Starts with a verb.
- Has a frequency or a specific week due.
- Can be done by a person, not merely "achieved".
- Can be scored this week.
- Is one of the critical few actions that drives the goal.

## Concepts Are Not Tactics

| Concept | Better tactic |
| --- | --- |
| Exercise | Do cardio 2x/week for at least 20 minutes |
| Get referrals | Ask for referrals 2x/day |
| Organize home | Clear one zone for 60 minutes x 6 days/week |
| Referrals | Ask two people for referrals every workday |
| Client follow-up | Send 5 personal notes/week |

## Milestones Are Not Tactics

| Milestone | Better tactic |
| --- | --- |
| Launch the referral campaign | Role play the referral talk 15 minutes/day for four weeks |
| File system ready | Create one file category per week until bills, tax, medical, and identity papers have homes |
| Clean the house | Pick one room/week and clear one zone for 60 minutes x 6 days/week |
| Finish admin backlog | Close or move one selected admin item every Tuesday and Friday |

## Nuance: One-Time Setup Actions

Some one-time actions can appear in a 12W Plan, especially when they unlock recurring execution.

Good one-time setup tactic:

```text
Create the referral script in Week 1.
```

Weak milestone disguised as tactic:

```text
Build the referral system.
```

Use this rule:

```text
If it is a concrete action with a week due, it can be a setup tactic.
If it is a finished state or deliverable, call it a milestone.
If it is a broad area, call it a concept.
```

## Scoring Rule

Weekly scoring works best when tactics have frequency.

If too many tactics are one-time deliverables, the scorecard becomes a project tracker instead of an execution tracker.
