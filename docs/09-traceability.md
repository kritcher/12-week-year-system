# Traceability

The 12WY artifacts must align as one chain:

```text
Vision -> 12W Goal -> Tactic -> Weekly Plan
```

If any link is missing, the work may still be useful, but it is not a 12WY tactic.

## Why This Matters

A plan can look complete while each layer points in a different direction:

- vision says one future matters
- goals come from backlog pressure
- tactics come from random project tasks
- weekly plan becomes a normal to-do list

Traceability prevents that drift.

## Trace ID Format

Use lightweight IDs:

```text
V1 -> G1 -> T1 -> W1
```

Example:

```text
V-NewBusiness -> G1 Close 10 qualified meetings -> T1 Ask referrals 2x/day -> W3 Mon-Fri
```

The exact naming does not matter. The chain does.

## Required Questions

For any item in the Weekly Plan:

```text
Which tactic did this come from?
Which goal does that tactic move?
Which vision theme created that goal?
```

If you cannot answer all three, move the item to maintenance, buffer, or backlog.

## What Belongs Where

| Item type | Where it belongs |
| --- | --- |
| Derived from vision and moves a 12W goal | 12WY tactic / Weekly Plan |
| Necessary but not tied to a 12W goal | Maintenance |
| Reactive small work | Buffer Block |
| Useful but not this cycle | Parked / backlog |
| New important work | Update the 12W Plan first, then pull into Weekly Plan |

## Alignment Review

Run this review weekly:

```text
1. Read the vision.
2. Read each goal.
3. For each tactic due this week, say which goal it moves.
4. For each weekly task, say which tactic it came from.
5. Remove or reclassify anything that cannot trace upward.
```

The goal is not bureaucracy. The goal is to stop the weekly plan from becoming a disguised inbox.
