# Weekly Execution

The weekly system exists to keep the 12 week plan alive.

## Weekly Plan

The weekly plan is one slice of the 12W Plan.

It should contain tactics due this week, not random tasks.

Every scored weekly item should name its source tactic ID:

```text
Vision -> Goal -> Tactic -> Weekly Plan item
```

Bad:

```text
- buy batteries
- clean inbox
- maybe research course
- call someone
```

Better:

```text
Goal 1
- T3: Ask for referrals two times per workday.
- T4: Send five personal notes this week.

Goal 2
- T6: Do cardio twice this week for at least 20 minutes.

Maintenance
- Pay urgent bill by Friday.
```

## Scorecard

Score execution:

```text
Execution Score = completed tactics / due tactics x 100
```

Do not score feelings.

Do not score lag results as execution.

Do not score random maintenance work as 12WY execution unless it traces to a tactic in the 12W Plan.

If a tactic was not done, mark it honestly. Then diagnose.

## Breakdown Diagnosis

When execution breaks, classify the reason:

| Breakdown | Meaning | Fix |
| --- | --- | --- |
| Plan problem | Tactic was vague, too large, blocked, or unrealistic | Rewrite the tactic |
| Execution problem | Tactic was clear but you did not do it | Fix environment, time block, or commitment |
| Reality changed | New constraint appeared | Re-plan deliberately |

## Weekly Accountability Meeting

A useful WAM can be short:

1. Score last week.
2. Name what slipped.
3. Diagnose plan vs execution.
4. Confirm this week's tactics.
5. Remove one obstacle.

Do not let the WAM become a general life update.

## Daily Loop

Morning:

```text
What tactics are due today?
```

During the day:

```text
Am I inside the block I chose?
```

End of day:

```text
What tactic was completed, and what must be protected tomorrow?
```

Traceability check:

```text
Did today's work come from a 12W tactic?
Which goal did it move?
Which vision theme did that goal come from?
```
