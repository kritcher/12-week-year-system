# Anti-Patterns

These are plans that look complete but are structurally wrong.

## Brain Dump First Trap

The trap:

```text
Brain dump -> triage backlog -> choose goals -> write tactics -> attach vision links later
```

This can produce a plan that looks mature:

- one to three goals
- project links
- vision links
- tactics
- weekly plan
- scorecard

But the direction can still be wrong.

## Why It Fails

Brain dumps are usually reactive. They contain open loops, stress, overdue tasks, and whatever is loud in the mind.

That material is useful, but it should not choose the cycle.

If goals come from the backlog first, the plan may optimize for relief instead of vision.

Adding a vision link after the goals are already chosen is not the same as deriving goals from vision. It is often rationalization.

## Correct Order

Use this order:

```text
Read vision -> reconnect emotionally -> ask what moves the vision this cycle -> choose intentional imbalance -> write 1-3 goals -> then inspect backlog for tactics or constraints
```

The backlog is allowed into the process after the vision has set direction.

## Practical Guardrail

Before writing a 12W Plan, answer:

```text
What part of the vision did I just read?
What future state am I emotionally connected to?
Why does this goal move that future state in the next 12 weeks?
Was this goal derived from vision, or did I pick it from backlog and attach a vision link afterward?
```

If the honest answer is "I picked it from backlog," stop and return to vision.

## AI Failure Mode

An AI can generate a plan that looks finished without noticing that it skipped vision.

Watch for these signs:

- the AI starts from a handoff, backlog, or task dump
- the AI asks for goals before reading vision
- the AI pastes vision links onto goals after the tactics are already written
- the plan feels complete but emotionally flat
- the user says "this is correct" but not "this matters"

## What To Do Instead

Ask the AI to run a derivation check:

```text
For each goal, show the vision sentence it came from, the 12 week movement it represents, and why it deserves weight over the parked alternatives.
```

If the AI cannot explain that chain, the plan is not ready.

## Broken Traceability Trap

The trap:

```text
Vision says one thing -> goals say another -> tactics are project tasks -> weekly plan is an inbox
```

This often happens after the plan is created. The first week looks fine, then urgent tasks leak in.

Guardrail:

```text
Every Weekly Plan item must answer:
Which 12W tactic did this come from?
Which goal does that tactic move?
Which vision theme created that goal?
```

If it cannot answer, classify it as maintenance, buffer, or backlog. Do not score it as a 12WY tactic.
