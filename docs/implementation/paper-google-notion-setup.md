# Paper, Google Docs, And Notion Setup

This system does not require Obsidian.

## Paper-Only

Use one folder or binder:

```text
Vision
Cycle Charter
12 Week Plan
Weekly Plan
Scorecard
Model Work Week
Commitment
Past Weeks
```

Paper works well if you actually look at it daily.

Weakness: harder to search and version.

## Google Docs And Sheets

Recommended:

- Google Doc for Vision.
- Google Doc for Cycle Charter.
- Google Sheet for 12W Plan, Weekly Plan, Scorecard, and lead/lag indicators.
- Calendar for Model Work Week blocks.

Use one folder per cycle.

## Notion

Recommended:

- One page for Vision.
- One page for Cycle Charter.
- One database for 12W Plan tactics.
- One database view filtered to current week.
- One scorecard database.
- Calendar view for Model Work Week.

Warning: Notion can become a design project. Keep the system boring.

## Universal Rule

The tool is secondary.

The system fails when:

- tactics are vague
- goals are too many
- weekly scoring is skipped
- time blocks are not protected
- the plan becomes a catch-all task manager
