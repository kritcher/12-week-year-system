# 12 Week Year Operating System

An unofficial, tool-independent guide for turning the ideas from *The 12 Week Year* into an execution system that a human and an AI assistant can run together.

This repo is not a book summary and is not affiliated with the authors. Read the original book for the source model. This repo focuses on the practical layer that people often get wrong when they ask an AI to help: vision before goals, goals before tactics, tactics before weekly scoring.

## What This Repo Prevents

Common AI mistakes this repo is designed to block:

- Turning a 12 week plan into a generic to-do list.
- Writing concepts as tactics, such as "exercise" or "study alpha".
- Writing milestones as tactics, such as "complete the course" or "finish the backtest".
- Filling the plan with more than three goals.
- Treating intentional imbalance as "choose three life areas" instead of choosing where energy goes.
- Using the Strategic Block as a private course block for one goal.
- Asking blank-state WH questions forever instead of helping the human recognize good options.

## Labels Used In This Repo

- **Book principle**: a core idea this repo treats as coming from the 12WY model.
- **Practical interpretation**: our operational reading of that idea.
- **Implementation recipe**: a suggested way to store or run it in a tool.
- **Example**: illustrative only; adapt it to your life.

When in doubt, keep the book principle stable and change the implementation recipe.
