# Cycle Setup Checklist

## Before Writing Goals

- [ ] I have read or reviewed the vision.
- [ ] I know which area is heavy this cycle.
- [ ] I know which areas are maintenance.
- [ ] I know which areas are parked.
- [ ] I accept the tradeoff.

## Goals

- [ ] There are one to three goals.
- [ ] Each goal is measurable.
- [ ] Each goal can plausibly be moved in 12 weeks.
- [ ] Each goal connects to the vision.
- [ ] No goal is just a theme.

## Tactics

- [ ] Every tactic starts with a verb.
- [ ] Every tactic has frequency or due week.
- [ ] Every tactic has a completion rule.
- [ ] Concepts have been rewritten into actions.
- [ ] Milestones have been rewritten into actions or moved out of the tactic table.
- [ ] The total tactic load can fit on the week.

## Model Work Week

- [ ] Strategic Block exists.
- [ ] Strategic Block keeps review, metrics, breakdown, and execution.
- [ ] Learning Blocks exist if study is required.
- [ ] Buffer Blocks exist for reactive work.
- [ ] Breakout Block exists for recovery.

## Weekly Execution

- [ ] Weekly Plan pulls only from the 12W Plan.
- [ ] Scorecard is ready.
- [ ] Past weeks will be preserved.
- [ ] There is a weekly review or WAM.
