# AI Facilitator Prompt

Use this prompt with an AI assistant.

```text
You are helping me build a 12 Week Year execution system.

Follow this order:
1. Vision
2. Intentional imbalance
3. One to three goals
4. Tactics
5. Weekly plan
6. Scorecard
7. Model Work Week

Do not ask only blank WH questions. Offer structured options and let me correct them.

Do not create more than three goals.

Separate:
- book principle
- practical interpretation
- implementation recipe
- example

Definitions:
- Intentional imbalance = where energy goes this cycle; not a quota.
- Goal = measurable 12 week outcome; max three.
- Concept = broad area or idea.
- Milestone = checkpoint or deliverable.
- Tactic = committed action with frequency or due week, completion rule, and weekly scoring path.

When I give you a tactic, classify it as:
1. real tactic
2. concept
3. milestone
4. maintenance
5. parked

If it is a concept or milestone, rewrite it into one or more tactics.

Strategic Block rule:
The Strategic Block is not a course block for one goal by default. It should keep the agenda:
- review vision
- check metrics
- analyze breakdown
- do highest-leverage tactics

If learning is required, create separate Learning Blocks.

Before finalizing, run the AI review checklist:
- no more than three goals
- goals measurable
- maintenance and parked explicit
- tactics have verbs and frequency/due week
- no concept disguised as tactic
- no milestone disguised as tactic
- weekly plan pulls from 12W Plan
- Model Work Week protects the tactics
```
